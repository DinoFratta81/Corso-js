DOMContentLoaded vs window.onload

  • DOMContentLoaded: DOM costruito, JS può accedere agli elementi(interactive)
  • window.onload: Tutto caricato(comprese immagini, CSS, ecc)

Interfaccie DOM principali

Node interface

Interfaccia base per tutti i nodi:

  • nodeType: Tipo di nodo(1=Element, 3=text, ecc)
  • nodeName: Nome del nodo
  • nodeValue: Valore del nodo
  • parentNode, childNodes, firstChild

Element interface

Estende node per elementi HTML:

  • tagName: nome del tag
  • attributes: Lista Attributi
  • classList: Gestione classi CSS
  • innerHTML, outerHTML: Contenuto HTML
  • textContent: Solo testo

HtmlElement Interface

Estende Element per elementi HTML specifici:

  • style: Gestione stili CSS
  • dataset: Attributi data
  • hidden: Nascondere/mostrae un elemento
